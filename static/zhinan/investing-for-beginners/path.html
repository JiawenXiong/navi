ROADMAP · RISK MANAGEMENT

学习路径与风险管理

本页综合仓库 README 与《投资入门指南》长文，把散落的知识点串成一条路线：先建立心态预期，再按美股、期权、加密三个模块推进，同时始终绑定风险管理。指南作者的核心观点很朴素：投资的本质是耐心 + 概率游戏 + 仓位管理，只买便宜的，不加杠杆，不追高。

01总框架：先配置，再概念，后纪律

FRAMEWORK · 出自仓库 README

STEP 1

资产配置先行

根据目标、期限和风险承受能力进行资产配置，把钱分为多份，各自有各自的用处。先明确这笔钱的用途和期限，再决定它承受多大的波动。

STEP 2

理解基础概念

复利、分散、交易成本和风险边界：看懂订单类型、财报和估值，理解利率、通胀和美元如何影响资产价格，理解各类投资的基础概念。

STEP 3

长期纪律代替情绪

用长期纪律代替情绪化追涨杀跌。外界信息会刺激心态，能找到可复现的框架并与外界信息"解离"，才可能长期盈利。

02分阶段学习路径

STAGES · 从心态到模块的推进顺序

STAGE 0

心态建设：先知道自己在哪里

指南作者用达克效应描述新手轨迹：从无知到愚昧之巅，跌入绝望之谷，再爬上开悟之坡。"我觉得我懂了"是最危险的心态，它让人在极端情况下梭哈全部身价。还没亏过大钱的人，要时刻提醒自己可能正站在山顶。另两条心态纪律：不试图证明自己，只对自己的投资结果负责；拒绝 FOMO，宁可错过，不要追高。作者的经验值：从零基础到形成稳定框架大约需要 3 年，至少经历一个牛市和一个熊市。

STAGE 1

基础资产与美股框架

补齐四类基础资产的理解：法币、债券、股票、衍生品。股票部分最重要的是看懂商业模式和财务数据，目标是能回答"这家公司值多少钱、未来会变好还是变坏"。配合 美股入门模块 的交易规则、财报与估值词条推进，理解利率、收益率曲线和宏观数据如何传导到股价。

STAGE 2

期权：先懂风险，再谈策略

认识收益结构、时间损耗、波动率和最大亏损，明白"方向看对仍可能亏损"的原因（IV Crush 与时间衰减）。卖方策略要预留尾部风险预算，0DTE 等高 Gamma 合约需要硬性仓位上限。配合 期权进阶模块。

STAGE 3

加密货币：钱包安全是第一课

先学私钥、助记词和授权安全，再碰交易；理解永续合约、资金费率和强平规则，识别授权钓鱼、地址投毒、Rug Pull 与代币解锁陷阱。配合 加密货币模块。仓库的顺序建议暗含一个原则：在能自己保管资产之前，不把大额资金带上链。

STAGE 4

复盘与迭代

交易复盘（仓库有期权交易日志词条）+ 定期回看决策依据。所有股票都有周期，涨多了就会跌，跌多了就会涨；验证一个框架能否复用，必须经过完整周期的时间考验。

03技术分析：概率工具，不是水晶球

TA · 指南作者的流派清单（均为概率，不是确定信号）

指南作者总结其接触过的数百位交易员经验：技术分析都是部分有用，没有完全 100% 有用的，这不是数学题而是概率游戏，只能帮助提高胜率。

作者认为部分有用的工具

裸K线形态学均线道氏理论威克夫操盘法动量斐波那契价格行为 PAVWAP筹码峰流动性

作者认为无法证伪、需要警惕的流派

波浪理论谐波江恩技术分析

理由：这类理论内部存在可无限自举的缺陷（如"千人千浪"），无法证伪即无法改进。

04仓位管理与离场纪律

SIZING · EXIT · 投资最难的两件事

CORE

投资的本质：耐心 + 概率 + 仓位管理

只在某种情况下出手，只在某种情况下离场，宁可不买，不盲目入场；一旦事情有变化，立即离场，不要恋战。两个流派本质上都是概率游戏：基本面赌商业世界的"大概率"，技术分析赌"市场这次还一样"。条件越确定、越少，才越值得上大仓位。

SPEC

投资还是投机（指南作者观点）

作者给出的参考界限：闲置资金较小的阶段，可以先投机感受市场，但要有外部现金流支撑，心态才不会变形；达到一定规模（作者以 10 万元人民币为例）后才谈"投资"，首要目标变成如何不亏钱。当一个股票你觉得可买可不买时，那就不买。

EXIT

三个离场观察信号（指南作者观点）

1 · 宝妈指数、健身教练指数：当最远离市场的群体开始入场时，信息传导已近最后一棒，增量资金接近枯竭。2 · 交易群体情绪亢奋：社群里普遍亢奋、持仓高度集中、互相打气时，大概率临近回调。3 · 短期翻倍警觉：正常标的几个月内涨两倍以上时，早期建仓的机构随时可能获利了结，中段入场者尤其要警醒。"最好的故事套最多的人"，买得便宜比学会止损更重要。

FAST

作者眼中的"捷径"：定投标普 500

指南作者认为，几乎唯一可穿越周期的做法是定投标普 500 指数，一直投到寿命终结之前，且没有仓位大小限制；其他"捷径"要么上不了仓位，要么风险远超想象，要么仅在特定周期有效。不选择这条捷径也正常，但要知道自己在放弃什么。

05风险管理检查清单

CHECKLIST · 下单前逐项核对

RISK-A杠杆与账户

  • 杠杆同时放大盈利和亏损，强平不为你选择最佳退出价
  • 10 倍杠杆不等于能承受 10% 的反向波动
  • 保证金账户保留缓冲，压力测试跳空与要求上调
  • 杠杆 ETF 与反向 ETF 不适合长期持有

RISK-B期权与衍生品

  • 先算最大亏损，再算潜在收益
  • 事件前的高 IV 意味着事件后的 IV Crush
  • 卖方策略设定权利金风险预算与尾部预案
  • 空头仓位始终预留指派与提前行权计划

RISK-C链上安全

  • 助记词不截图、不存云盘、不输入任何网页
  • 转账先小额测试，核对地址首尾多位
  • 钱包授权最小化，闲置授权及时撤销
  • 大额资产用冷钱包，先测恢复流程再转入

RISK-D通用纪律

  • 只买自己理解的标的，可买可不买就不买
  • 所有股票都有周期，没有永远上涨的标的
  • 宁可错过，不要追高；不跟 KOL 的单
  • 投资框架未经周期验证前，仓位就是风险
指南原文的一句话总结：投资其实是一件非常简单的事情，只买便宜的，不加杠杆，不追高；难的从来不是知道，而是在信息噪音里长期做到。

方法学：这份指南如何读证据

ACM 指标、HR/RR/95% CI 怎么读、A/B/C/D/U 实用分级、四档核验结论，以及为什么旧版“加 X 年寿命”的写法被仓库自己否定了。

为什么只看 ACM（全因死亡率）

ACM 指一段时间内死于任何原因的比例。只盯着单一疾病的死亡率会掉进两个坑：一是某干预降低了心脏病死亡却推高了其他死亡，总死亡没变；二是拿“癌症发病下降”冒充“死亡下降”。台账里不少条目的核验结论就卡在这里，例如复合维生素降低的是男性医生的癌症发病（HR 0.92），而非全因死亡；泡澡研究降低的是心血管发病，根本没有报告 ACM。

因此 evidence.json 的每条记录都注明 design（研究设计）、population（人群）、comparison（对比口径）和 effect（效应量）。比较口径不同时，数字之间没有可比性：同样是“喝含糖饮料”，每增加一份的 HR 1.07 与最高摄入组的 HR 1.21 完全不是一回事。

如何读懂这些数字：HR、RR、95% CI 速成

全站条目里反复出现"HR 0.53（95%CI 0.40–0.69）"这样的写法。这一节用大白话解释每个字段是什么意思、怎么判断好坏、最容易读错的地方在哪里。

指标怎么读好坏判断常见误读
ACM 全因死亡率一段时间内死于任何原因的比例。本站统一用它当主要终点。不看单一病种、只看"总死亡有没有降"。把"癌症发病下降"当成"死亡下降"；某干预降了心脏病死亡却推高其他死亡，总死亡没变。
HR 风险比参照组（不吃/不做的人群）固定为 1。HR 0.53 读作"随访期内死亡风险约为不吃/不做人群的 53%"，即相对降低约 47%；HR 1.34 就是风险高 34%。<1 风险降低，>1 风险升高，离 1 越远效应越大。当成绝对风险；换算成"多活几年"（仓库已明确否定寿命换算）。
RR 相对风险和 HR 同一套参照系：RR 0.83 就是该组风险约为参照组的 83%。多用于固定随访期或"高摄入组 vs 低摄入组"这类分类比较；HR 则用于随访时间不一、随时有人退出或死亡的生存分析。同 HR：<1 降低、>1 升高。和 HR 混着比较"谁的数字大"；两者口径不同时没有可比性。
95% CI 置信区间真实值大概率落在的区间。区间整体<1 或整体>1（不含 1），通常认为统计显著；跨 1 则结论不确定。看区间是否跨 1，比只看点估计更可靠。只看点估计不看区间，把"看似降低"当成"确实降低"。

示例一：HR 0.53（95%CI 0.40–0.69）

逐字段拆：HR 0.53 = 挥拍参与者在随访期内的死亡风险约为未参与者的 53%，相对降低约一半；95%CI 0.40–0.69 = 真实风险比大概率落在 0.40 到 0.69 之间，区间整体小于 1，这个"降低"的方向比较可信。但它是观察性关联（等级 B），不是随机试验，也不能换算成"多活 X 年"。

示例二：HR 0.99（95%CI 0.87–1.12）

逐字段拆：HR 0.99 看似"风险低 1%"，几乎等于没有差别；CI 0.87–1.12 跨过了 1，说明连"到底是降一点还是升一点"都确定不了。这是 VITAL 维生素 D 试验的结果：一份高质量的阴性证据。统计上"显著"也未必有用，HR 0.99 这类即使显著也几乎等于没效果。

统计显著 ≠ 效应大。样本量足够大时，HR 0.99 也能达到"统计显著"，但对个人几乎没有意义。判断一条证据要看三件事合在一起：点估计离 1 多远、区间是否跨 1、研究设计是观察还是随机。
相关 ≠ 因果。本站绝大多数条目是观察性研究：研究者只是"观察"谁吃得多、谁做得勤，人群自己选择的。吃坚果多的人可能本来就更注意健康，这部分差异无法完全剔除。随机对照试验（RCT）把人随机分到干预组和安慰剂组，才能把差异归因于干预本身。所以等级 A 也可能是阴性证据（如维生素 D），等级 B 的强关联（如挥拍运动）也只能提示"值得做"，不能保证"做了就降这么多"。

A/B/C/D/U：项目自定义的实用分级

这不是正式的 GRADE 系统。仓库在 metadata 中反复强调：A/B/C/D/U 是按“对 ACM 结论的适用性”给出的实用分级，描述的是证据设计质量，不是建议强度。

A 直接 ACM 的随机证据

如 SSaSS 低钠盐试验（率比 0.88）、VITAL 维生素 D 试验（HR 0.99）。注意：A 可以是高质量的阴性证据，即“做了严谨的随机试验，没看到效果”，这不等于推荐延寿，也不能排除较小效应。

B 多队列或高质量大队列

如挥拍运动（HR 0.53）、睡眠时长多队列合并（HR 1.34/1.48）。关联稳健但属观察性，不能当因果处方。

C 单队列或局限明显

如每日步数 CARDIA 队列（仅 72 例死亡）、辣椒两队列。估计不稳定或混杂明显。

D 间接或替代证据

动物实验（恒河猴热量限制）、生态学回归（181 国钠摄入）、以皮肤癌代理日晒、替代终点（NMN 的代谢指标）。“无直接 ACM 证据”不等于“已证明无效”。

U 证据缺失或无法核验

无法访问原文、仅书目可查，或数据不足以判断时如实标注，不强行给结论。

等级的两个易错点

  • 期刊名气不加分：发在顶刊的生态学研究仍是 D。
  • 等级针对“该条对 ACM 的证据”，同一因素不同人群可以分属不同等级。

四档核验结论

结论含义典型例子
支持但需限定原数字可在原论文复核，但适用人群、口径或因果解释有边界。睡眠 ≥10 小时 ACM 男 1.34、女 1.48：数字吻合，但长睡可能反映潜在疾病，不能强令长睡者减到 7 小时。
部分支持部分说法成立，部分是拼贴、错配或跨研究混写。白肉条目把 JAMA 与 BMJ 两篇论文的数字混在一段；核桃“健康预期寿命多 1.3 岁”实为 60 岁总预期寿命的模型估计。
需纠正关键表述与原文不符，流传版本存在实质性错误。“吃辣椒总死亡降 61%”实为意大利队列脑血管死亡 HR 0.39；“吃盐多更长寿”是国家层面生态回归，作者自己声明不可用于营养干预。
无直接 ACM 证据证据存在但终点不是 ACM，或无法推断个体死亡风险。泡澡（CVD 发病）、NMN（代谢替代指标）、恒河猴热量限制（动物）、抗衰药综述（机制与早期临床）。

阅读原则：六个不要

1. 不要把 HR/RR 换算成寿命年数

HR 0.85 的意思是该组死亡风险约为参照组的 85%，仅此而已。它不是绝对风险差，不是“多活五年”，也无法换算成任何个人寿命增益。

2. 不要跨条目相加或相乘

“挥拍运动降 47% 加上喝茶降 15%”在统计上不成立。各研究的参照组、人群和模型都不同，效应不可叠算。

3. 不要把关联当因果

观察队列里做家务的老人死亡少，可能因为身体好才做得了家务。核验版给每条都保留了 limitations 字段，混杂与反向因果是常客。

4. 不要混淆终点

发病、替代指标、复合终点都不是 ACM。就寝时间研究中可核验的是“死亡加非致死心血管事件”复合终点 HR 1.09/1.10，二手转传的“早睡 ACM 高 43%”未能在原文摘要复核。

5. 不要忽略人群边界

低钠盐试验的对象是有卒中史或高龄高血压的中国农村人群；二甲双胍降低 36% 死亡的对象是超重新诊断糖尿病患者。换个人群，结论可能完全不同。

6. 不要把“未见获益”读成“有害”

队列里复合维生素使用者 ACM 轻微升高（HR 1.04），可能是健康差异的反向选择；随机试验 CI 跨 1 只说明未见显著效应，不证明危险。

关于旧版“加 X 年寿命”：早期 README 曾给每个习惯标注“+3 年”“-12 年”式的寿命换算。核验团队确认这些换算没有依据并已在新版中放弃：例如“二甲双胍让糖尿病人比正常人多活 3 年”来自一项回顾性匹配队列的生存时间比（STR 0.85），不能转为固定年数。本站全站不使用任何寿命年数换算。
来源可溯：evidence.json 的每条记录都附 sources 数组，含论文标题、DOI、阅读深度（摘要、全文关键段或仅书目）和核验状态。第二轮审计实际重读了 14 条记录的 24 个来源，两处记录（氨糖、睡眠时长）的表述据此修订。未复核的 49 条记录在 metadata 中如实说明，不冒充全面审查。

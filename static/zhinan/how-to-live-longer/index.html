程序员延寿指南：一份被逐条核验过证据的长寿常识手册

HowToLiveLonger 是 GitHub 上广受欢迎的开源项目，围绕全因死亡率（ACM）整理了食物、运动、睡眠和日常习惯的研究结论。本站基于仓库的 README 与 data/evidence.json 证据台账制作，把原始数据转成可以直接在浏览器里读完的中文页面。

重要提醒：仓库的核验版数据已经放弃了早期“某习惯等于加 X 年寿命”的换算写法。HR、RR 等相对指标不能相加、不能相乘，也不能换算成个人寿命年数。全站所有数字均来自仓库数据，未做任何推算或编造。

这个项目在做什么

面向普通人的循证清单

项目把散落在论文里的长寿研究汇总成可执行的行动项：运动、睡眠、饮食、补剂、吸烟与环境暴露，每一条都标注了证据等级、研究人群、效应量和置信区间，并给出谨慎的行动建议。

先核验，再传播

证据团队对原始引文逐条回溯到论文原文：核对数字是否真实存在、结局是不是全因死亡、引文和结论是否错配。中文 README 第 3 至 6 节的 77 次文本引用被合并为 74 条独立出处，逐条保留了台账。

敢于否定自己

旧版 README 曾按“加或减多少年寿命”给每个习惯打分。核验后仓库明确否定了这种换算：观察性研究的 HR 不是个人因果效应，多个条目的收益也不能累加。本站遵循新版口径。

给 AI 和人类共用

仓库提供结构化 JSON 证据数据，可供 AI 助手引用作答，也欢迎社区通过提交记录补充和纠错。所有条目都附原始论文链接，读者可以自行查证。

三分钟读懂方法论

核心指标是 ACM（全因死亡率）。只看单一疾病会被“降低了某病风险却没降低总死亡”的结论误导，因此台账统一以全因死亡为主要终点，个别条目另注明心血管死亡、癌症发病等替代终点。

A 随机试验证据

直接 ACM 终点的大型随机试验。注意 A 只表示设计质量，高质量的阴性结果（如维生素 D 未见获益）同样可以是 A。

B 高质量队列

多队列汇总或高质量大型队列的直接 ACM 关联，证据较强但不构成因果证明。

C 单队列或局限明显

单一队列、事件数少或混杂显著，直接 ACM 证据有限。

D 间接证据

动物实验、生态学分析、替代终点或间接暴露推断，不能直接外推到个体人类的 ACM。

U 证据缺失

尚无可靠证据，与“已证明无效”是两回事。

四档核验结论

支持但需限定、部分支持、需纠正、无直接 ACM 证据。不少流传甚广的说法最终落在“需纠正”一档，详见误读纠正页。

逐条解读

维生素 D A（针对缺乏与骨骼健康）

NIH ODS 的结论是：维生素 D 对钙吸收和骨骼健康必不可少，缺乏者补充可改善骨密度、降低佝偻病和骨软化风险；老年人与缺乏风险高的人群补充联合钙剂可降低骨折风险。但维生素 D 大规模干预研究（如美国 VITAL 试验）显示，对维生素 D 不缺乏的一般人群，每日 2000 IU 并未显著降低癌症或心血管事件风险。中国营养学会推荐成人每日 10 微克（400 IU），可耐受最高摄入量（UL）为 50 微克（2000 IU）。长期超量可致高钙血症。

B 族维生素：B12 与叶酸 A（针对特定人群）

维生素 B12 几乎只存在于动物性食品，纯素饮食者如不补充，缺乏几乎不可避免；老年人因胃酸和内因子分泌下降，吸收率降低，也是经典缺乏人群。B12 缺乏可导致巨幼细胞贫血和不可逆的神经损害。叶酸的核心价值在备孕期：从怀孕前三个月开始每日 400 微克，可将胎儿神经管缺陷风险显著降低，这是 WHO、各国疾控机构与中国营养学会的一致推荐。注意：合成叶酸（补充剂、强化食品）的 UL 为每日 1000 微克，大剂量叶酸可能掩盖维生素 B12 缺乏的血液学表现而延误神经损害的诊断。

铁 A（针对确诊缺铁性贫血）

铁补充剂对确诊缺铁性贫血的疗效毫无争议，是"特定人群加特定目的"的典型 A 级场景，WHO 亦将孕产人群补铁列为公共卫生措施。但铁会在体内蓄积，男性与绝经后女性在不缺铁时补铁没有获益只有风险：胃肠道刺激与便秘常见，过量可致中毒，儿童误服成人铁剂可致命。是否缺铁应以血常规与铁代谢检查（铁蛋白、血清铁、转铁蛋白饱和度）为准，补铁后须复查并追查缺铁原因，具体决策见理性决策页铁一节。

蛋白粉、益生菌、辅酶 Q10 B / C

蛋白粉的本质是食物蛋白的浓缩形式，运动员与增肌期人群用它方便地达到每日蛋白质总量目标（力量训练者约每公斤体重 1.4 至 2.0 克），这有充分证据；但蛋白粉本身不比鸡胸肉、鸡蛋、牛奶更"高级"。益生菌的关键在"菌株特异性"：Cochrane 评价支持特定菌株（如鼠李糖乳杆菌 GG、布拉氏酵母菌）可缩短儿童抗生素相关腹泻约一天；对肠易激综合征、某些过敏性疾病的部分菌株也有阳性结果，但均限于特定菌株、剂量与人群，不能泛化为"益生菌都能调节免疫"。辅酶 Q10 用于他汀相关肌肉症状的研究结果不一致，Cochrane 对心衰辅助治疗的评价也持谨慎态度，目前不构成常规推荐。

褪黑素、氨基葡萄糖、锌、镁、叶黄素、纤维 B / C

褪黑素对时差综合征和睡眠时相延迟障碍（晚睡晚醒型）有一定证据，被广泛用于倒班和跨时区人群；对慢性失眠，各国指南首选失眠认知行为治疗（CBT-I）而非长期服药。氨基葡萄糖治疗膝骨关节炎的经典大型试验（GAIT）主要终点阴性，各指南态度不一，整体效果即使存在也很小。锌含片在感冒开始 24 小时内使用可能略缩短病程（Cochrane 及后续评价结论偏谨慎），但过量锌干扰铜吸收，UL 为每日 40 毫克。镁对偏头痛预防有一些阳性试验，便秘时枸橼酸镁本就是常用药物。叶黄素与玉米黄素是 AREDS2 配方成分，对已有中期老年黄斑变性的患者可减缓进展，对未患病的一般人群预防作用不明。膳食纤维补充剂（洋车前子壳）降胆固醇、改善便秘的证据较好，但全谷物、蔬果、豆类同时带来钾、镁与植物营养素，永远优于提纯纤维。

维生素 C C

Cochrane 系统评价的总体结论：规律补充维生素 C 不能降低普通人群感冒的发生率，仅在部分高强度体力活动或寒冷环境中可能小幅获益；感冒后开始补充的获益基本为零。梅奥诊所指出，对多数人而言维生素 C 对感冒的作用很小，可能略缩短病程。成人推荐量约每日 100 毫克，一个中等大小的橙子加一份蔬菜即可满足；UL 为 2000 毫克，过量可致腹泻并增加肾结石风险（尤其男性）。

复合维生素 C

USPSTF 对"复合维生素预防心血管疾病和癌症"的声明结论是：现有证据不足以评估获益与危害的平衡，不足以作出常规推荐；同时明确反对使用 β 胡萝卜素或维生素 E 补充剂来预防心血管病和癌症。哈佛公共卫生学院的态度也一致：复合维生素并非必需，但对饮食质量差、无法均衡进食的人（如部分老年人）是一种低成本的"营养保险"，绝不能弥补不良饮食结构的全部问题。

钙与鱼油 Omega-3 C

USPSTF 曾评估社区居住成年人补充维生素 D 与钙（不分剂量）预防骨折的证据，结论是低剂量（每日钙低于 1000 毫克、维生素 D 低于 400 IU）未显示预防骨折获益。大型观察研究还提示钙补充剂可能与肾结石及心血管钙化风险相关，因此中国营养学会与国际主流建议都是奶制品、豆制品、深绿色蔬菜优先。鱼油方面：VITAL、ASCEND 等试验显示，一般人群中普通剂量鱼油未能显著降低心血管事件；REDUCE-IT 中获益的是高纯度大剂量 EPA 乙酯（二十碳五烯酸乙酯），属于处方药而非保健品，且该结果不能外推到普通鱼油。梅奥与哈佛的共识是：每周吃两次富脂鱼优于吃鱼油胶囊。此外鱼油有轻度抗血小板作用，与华法林等抗凝药合用须咨询医生。

NMN/NR、白藜芦醇与胶原蛋白 D

NMN（烟酰胺单核苷酸）与 NR（烟酰胺核糖）作为 NAD 前体，理论上有延缓衰老的可能，但人体研究规模小、周期短，主要终点是 NAD 水平等替代指标，尚无发病或死亡等硬终点证据；中国国家市场监管总局未将 NMN 列入保健食品原料目录，以 NMN 为原料的产品不得作为保健食品销售，跨境电商渠道购买者需自担监管差异风险。白藜芦醇的人体获益同样未获证实。胶原蛋白口服后与其他蛋白质一样被消化为氨基酸和小肽，不存在"定向补充皮肤胶原蛋白"的机制；少数小型研究显示水解胶原蛋白肽可能小幅改善皮肤弹性，但研究规模小、有厂商资助背景，不足以支撑宣称。NMN/NR 与胶原蛋白的"补不补、怎么吃、花多少钱"逐项分析见理性决策页对应决策卡；白藜芦醇不单设决策卡，因为既无对应缺乏场景，也无权威机构支持的常规补充理由，结论就是不推荐。

速览品类逐条解读

以下 40 段与三张速览表逐行对应，比核心品类的解读更精简：先说主打声称，再说机构立场，最后一句理性结论。

速览一：维生素与矿物质

碘 A

主打补碘、改善甲状腺功能与代谢。备孕期及孕期补碘对胎儿脑发育证据充分，WHO 与中国营养学会均推荐孕前起增加碘摄入（孕妇推荐量约每日 230 微克）。碘充足地区的一般人群额外补碘无获益，反而可能诱发甲状腺功能异常。结论：孕产人群推荐，一般人群不需要。

钾 B

主打降血压、防中风。EFSA 认可食物来源的钾有助于维持正常血压，WHO 也建议从果蔬豆类获取。但钾补充剂单剂剂量受严格限制，血钾过高可致命，肾功能不全者禁用，补钾须遵医嘱。结论：靠蔬果补钾，别自服钾片。

维生素 K2 C

主打"引钙入骨"、防骨质疏松与血管钙化。维生素 K 参与凝血与骨钙代谢的基础作用明确，但 K2 补充剂改善骨密度或防止血管钙化的干预证据有限且不一致。普通饮食者缺乏维生素 K 罕见。结论：证据不足，一般人群不需要。

硒 C

主打抗氧化、防癌。SELECT 等大型随机试验未见硒补充降低癌症风险，NIH ODS 指出部分研究还提示补硒与 2 型糖尿病风险升高相关。缺硒地区人群应按医嘱补。结论：一般人群不建议。

铬（吡啶甲酸铬） C

主打控糖、减肥。NIH ODS 与系统评价认为铬对 2 型糖尿病血糖控制的效果即使存在也很小，减重宣称证据不足。结论：证据不足，控糖靠饮食、运动与规范用药。

维生素 A（视黄醇） C

主打护眼、护肤、抗感染。对确诊缺乏者补充有效，WHO 在缺乏地区将其列为公共卫生措施；但一般人群额外补充无慢病预防证据。安全警示：过量有肝毒性，孕期摄入超过每日 3000 微克视黄醇当量（UL）有致畸风险，动物肝脏与含视黄醇产品须控量。结论：饮食达标者不补，孕期尤其注意上限。

烟酰胺（口服护肤） C

主打口服美白、修护屏障。小型研究提示或略改善皮肤屏障与色沉，一项澳大利亚试验提示高剂量或降低高危人群皮肤癌发生率，但属医生评估范畴。日常口服美白宣称证据有限。结论：不必需，想美白先做好防晒。

维生素 E D

主打抗氧化、预防心脑血管病与癌症。USPSTF 明确反对用维生素 E 补充剂预防心血管病和癌症；部分大剂量试验还提示出血性卒中风险升高。结论：一般人群不建议。

生物素 D

主打防脱发、美甲美发。NIH ODS 指出防脱宣称缺乏可靠人体证据，仅罕见生物素代谢障碍等特定缺乏状态需要补充；大剂量还会干扰甲状腺激素等化验结果。结论：证据不足，脱发先查病因。

硼 D

主打健骨、提高睾酮。人体研究稀少，健骨与激素宣称均无可靠证据，NIH ODS 亦无支持性结论。结论：证据不足，不建议。

速览二：抗氧化、新兴成分与功能脂类

NAC（乙酰半胱氨酸） B

主打抗氧化、祛痰、护肝"清肺"。稀释痰液与对乙酰氨基酚过量解毒证据充分，但均属药品用途；作为保健品的日常宣称证据不足。结论：一般人群不需要，别把药当保健品吃。

DHA 藻油 B

主打胎儿脑发育、婴幼儿智力。中国营养学会推荐孕中晚期及乳母每日补充 200 毫克 DHA，EFSA 亦认可 DHA 对正常脑视觉发育的贡献。一般成年人每周吃两次富脂鱼即可达标。结论：孕产人群可能有用，其他人吃鱼即可。

葡萄籽提取物（OPC） C

主打抗氧化、护血管、美颜。小型研究提示对血压等替代指标或有小幅影响，EFSA 未认可其健康声称，防病宣称证据不足。结论：证据不足，一般人群不必需。

番茄红素 C

主打护前列腺、抗氧化。证据主要来自观察性研究且结果不一致，干预试验薄弱，现有结果不足以支持补充剂降低前列腺癌风险。结论：熟番茄等食物可以吃，胶囊证据不足。

谷胱甘肽（口服） C

主打口服美白、护肝排毒。口服生物利用度低，小型短期研究提示或略改善肤色，规模小质量低且多有厂商资助背景；护肝排毒宣称无证据基础。结论：证据不足，一般人群不必需。

大豆异黄酮 C

主打缓解更年期潮热、护骨。NCCIH 与 Cochrane 均认为其对潮热的效果幅度小且研究结果不一致，护骨宣称也不充分。结论：证据有限，症状明显者应就诊妇科。

α-硫辛酸 C

主打抗氧化、改善糖尿病神经病变。部分临床试验支持其缓解糖尿病周围神经病变症状，部分国家按药品管理；作为保健品自用的剂量与证据都不明确。结论：特定人群可能有用，须遵医嘱。

甘氨酸 C

主打改善睡眠、抗衰。小型研究提示睡前服用或略改善主观睡眠质量，规模小；抗衰与"助胶原合成"宣称缺乏人体证据。结论：证据不足，一般人群不必需。

牛磺酸 C

主打抗衰、护心、提升运动表现。抗衰说法源于动物研究，人体获益证据不足，EFSA 亦未认可相关声称。结论：证据不足，功能饮料里的牛磺酸不是喝它的好理由。

鱼肝油 C

主打同时补维生素 A 与 D。本质是两种维生素的老式载体，适量可用，但维生素 A 容易过量，孕期尤其须防致畸剂量。现代做法是单补维生素 D 更可控。结论：特定场景可用，注意维生素 A 上限。

MCT 油 C

主打快速供能、生酮、减脂。在生酮饮食与临床营养支持等特定场景有工具价值，对普通人减脂效应小且可能肠胃不适。结论：特定人群可能有用，一般不需要。

虾青素 D

主打"最强抗氧化剂"、护眼抗衰美肤。人体硬终点证据缺失，现有研究多为小规模替代指标试验，宣称远超数据。结论：证据不足，不建议。

麦角硫因 D

主打"长寿维生素"、抗氧化抗衰。研究集中于细胞与动物实验，人体获益证据不足。结论：抗衰宣称无据，不建议。

AKG（α-酮戊二酸） D

主打抗衰老、延寿。延寿数据来自线虫与小鼠，人体研究缺失。结论：证据不足，不建议。

月见草油 D

主打调节内分泌、缓解经前不适与湿疹。多项随机试验未能证实其有效，EFSA 拒绝相关健康声称。结论：一般人群不建议。

速览三：健身减脂、睡眠情绪与红曲

红曲 B

主打降血脂、"天然他汀"。其降胆固醇成分即洛伐他汀样物质（莫纳可林 K），效应与他汀相当。安全警示：与他汀类药物叠加会增加肌肉与肝损伤风险，市售产品莫纳可林含量波动且可能污染橘青霉毒素。结论：特定人群在医生指导下可能有用，不可自行与他汀叠加。

肌酸（一水肌酸） B

主打增肌、提升力量与短时高强度表现。ISSN 立场文件支持一水肌酸配合力量训练提高表现，是运动补剂中证据最扎实的一类；无训练需求者无获益。结论：规律训练者可能有用，详见决策卡。

HMB C

主打保肌、抗分解。对老年、卧床等分解代谢旺盛人群或有小幅保肌作用；训练与蛋白质摄入充足者无额外获益。结论：特定人群或有用，一般健身者证据有限。

谷氨酰胺 C

主打护免疫、修肠道。重症等临床用途按药品管理；健康人的免疫与健身宣称在现有评价中证据不足。结论：一般人群不需要。

白芸豆提取物 C

主打"碳水阻断"、大餐救星。对淀粉吸收有小幅抑制，但减重研究规模小质量低，效果远不及营销口径。结论：证据有限，别指望它抵消大餐。

茶氨酸（L-茶氨酸） C

主打放松、抗焦虑。小型研究提示或有助于放松与缓解主观压力，效应温和；作为茶饮天然成分无害，单独高剂量胶囊证据有限。结论：喝茶即可，不必额外买胶囊。

5-HTP C

主打改善情绪、助眠、抑制食欲。抑郁相关试验小而陈旧。安全警示：与抗抑郁药合用有血清素综合征风险，历史上相关产品曾检出污染物致严重疾病。结论：有安全顾虑，不应自行使用。

色氨酸 C

主打助眠、改善情绪。作为蛋白质的组成氨基酸日常饮食即可获得，高剂量助眠证据不一致；与抗抑郁药相互作用风险与 5-HTP 类似。结论：一般人群不需要。

左旋肉碱 D

主打"燃脂"、减脂。meta 分析显示对普通人减重无效果；仅遗传性肉碱缺乏等患者在医嘱下使用，肾病患者体内蓄积有风险。结论：减脂宣称证据不足，不建议。

CLA 共轭亚油酸 D

主打减脂增肌塑形。对体脂的影响即使存在也极小，常见胃肠不适，部分研究提示对血脂代谢不利。结论：不建议。

BCAA D

主打增肌、缓解酸痛。在蛋白质总量充足的前提下不优于完整蛋白，日常饮食蛋白充足者无需额外补充。结论：一般不需要，"必需支链"话术不构成购买理由。

ZMA（锌镁维 B6） D

主打提升睾酮、改善睡眠与恢复。在不缺锌镁的人群中，提升睾酮与运动表现的宣称已被试验否定。结论：证据不足，不建议。

藤黄果 D

主打抑制食欲、燃脂减肥。meta 分析未见减重获益。安全警示：监管数据库与文献多次报告相关产品肝损伤病例，部分国家已发布警示。结论：有安全顾虑，不建议使用。

覆盆子酮 D

主打"燃脂神器"。减脂证据仅来自细胞与动物实验，无合格人体试验。结论：证据不足，不建议。

GABA D

主打安神助眠、缓解焦虑。口服 GABA 难以通过血脑屏障，助眠宣称缺乏可靠人体证据。结论：证据不足，一般人群不建议。

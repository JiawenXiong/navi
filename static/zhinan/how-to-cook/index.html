新手入门路径

按这个顺序练，四周就能稳定做出一桌两菜一汤

1

第一周：搭好厨房，学会用刀

对照学前准备页的清单备齐基础工具和高频调料，练稳握刀、猫爪手和切片。目标不是快，是稳。

2

第二周：从两道零失败素菜开始

先做蚝油生菜和蒜蓉西兰花：只需要焯水加淋汁，几乎不可能翻车。再挑战西红柿炒鸡蛋和酸辣土豆丝。

3

第三周：掌握肉菜的核心工序

焯水、去腥、煎制、收汁。跟着可乐鸡翅和简易红烧肉的步骤走，重点是学会看火候和撇浮沫。

4

第四周：一桌完整的饭

用玉米排骨汤或西红柿鸡蛋汤配一锅蛋炒饭，饭后来一份柠檬水。至此你已能独立开火请客。

关于这个项目

HowToCook（程序员做饭指南）是一个由社区驱动和维护的开源项目。作者在宅家做饭时发现网上的菜谱写法千奇百怪，对习惯了形式语言的程序员极其不友好，于是决定结合实际做菜经验，用更清晰精准的描述整理常见菜的做法。

项目托管在 GitHub，所有菜谱以 Markdown 维护，非常欢迎任何人通过 Pull Request 贡献新菜或修正问题。本站收录了仓库全部 373 道菜谱与入门技巧，整理成便于阅读的多页站点，内容忠于仓库原文。

想浏览完整菜谱库或参与贡献，请访问 GitHub 仓库 Anduin2017/HowToCook。
